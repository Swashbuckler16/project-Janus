# Empirical Benchmark Datasets

This directory contains representative empirical evaluation datasets captured using the Python Attack Controller against the target Android device over network/ADB test harness.

## Directory Structure

```text
Results/
├── baseline_sha256_unprotected.csv     # Baseline: Unsalted single-iteration SHA-256 with no rate limiting
├── defended_tiered_lockout.csv         # Defended: Hardware PBKDF2 + Multi-Tier Progressive Lockout & Token Bucket
├── exhaustive_bruteforce_run.csv       # Large-scale attack run (~4,800 consecutive requests)
├── plots/                              # Automated visualization graphs generated by analyze_results.py
│   ├── latency_comparison.png          # Boxplot & distributions comparing SHA-256 vs PBKDF2
│   ├── keyspace_exhaustion.png         # Attack duration projection across defense tiers (Log scale)
│   └── progressive_lockout_steep.png   # Attack timeline demonstrating HTTP 429 escalation
├── archive/                            # Archived historical test runs (.gitignored)
└── README.md                           # Documentation and reproduction guide
```

## CSV Schema

Each row logs an individual verification request sent to the embedded test harness endpoint (`/lab/verify`):

| Column | Description | Example |
| :--- | :--- | :--- |
| `timestamp` | UTC/Local timestamp of request execution | `2026-10-24 17:08:43` |
| `pin` | 4-digit candidate PIN tested by the attack harness | `0000` |
| `success` | Result of verification: `True`, `False`, or `RATE_LIMITED_429` | `False` |
| `server_attempt` | Total failed attempts counter maintained by device defense engine | `5` |
| `response_time_ms` | Processing time on Android device (nanos converted to ms) | `445` |
| `network_time_ms` | End-to-end round-trip latency measured at attack harness client | `462.15` |
| `algorithm` | Active hashing engine or defense tier active during response | `PBKDF2_HMAC_SHA256` |
| `constant_time` | Boolean confirming constant-time verification flag | `True` |
| `hardware_backed` | Boolean confirming Keystore hardware-backed TEE/StrongBox key | `True` |

## Generating Publication Plots & Audit PDF Reports

To analyze these datasets and generate the charts:

```bash
cd "Python attack controller/Attack-Controller"
python analyze_results.py
```

To generate a detailed forensic audit PDF report from any attack run:

```bash
# Generate report for a specific CSV run:
python generate_attack_report.py --csv Results/defended_tiered_lockout.csv

# Or automatically generate the PDF report when running an attack:
python main.py --pdf
```
